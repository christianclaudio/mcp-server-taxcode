# Va. Code Ann. § 58.1-302 — Definitions - Resident and Actual Resident

- **Jurisdiction:** VA
- **Corpus:** Va. Code
- **Effective Year:** 2024
- **Superseded Year:** Current / In Force
- **Source:** [https://law.lis.virginia.gov/vacode/title58.1/chapter3/section58.1-302/](https://law.lis.virginia.gov/vacode/title58.1/chapter3/section58.1-302/)
- **Hierarchy:** `Va. Code > Title 58.1 > Chapter 3 > Article 1 > § 58.1-302`
- **Cross References:** `Va. Code Ann. § 58.1-320`, `Va. Code Ann. § 58.1-342`

## Operative Statutory Language (English)

Defines resident individual as one domiciled in Virginia, or an actual resident who maintains a place of abode and spends in the aggregate more than 183 days of the taxable year in Virginia.

## Texto Estatutario Oficial (Español)

Define individuo residente como quien tiene domicilio en Virginia, o un residente de hecho que mantiene morada y pasa más de 183 días en total del año contributivo en Virginia.
