# Va. Code Ann. § 58.1-342 — Reciprocal Tax Agreements for Commuters

- **Jurisdiction:** VA
- **Corpus:** Va. Code
- **Effective Year:** 2024
- **Superseded Year:** Current / In Force
- **Source:** [https://law.lis.virginia.gov/vacode/title58.1/chapter3/section58.1-342/](https://law.lis.virginia.gov/vacode/title58.1/chapter3/section58.1-342/)
- **Hierarchy:** `Va. Code > Title 58.1 > Chapter 3 > Article 8 > § 58.1-342`
- **Cross References:** `Va. Code Ann. § 58.1-302`

## Operative Statutory Language (English)

Authorizes reciprocal agreements with contiguous jurisdictions (DC, Maryland, West Virginia, Pennsylvania, and Kentucky) exempting commuter compensation from non-resident withholding.

## Texto Estatutario Oficial (Español)

Autoriza acuerdos recíprocos de exención con jurisdicciones limítrofes (DC, Maryland, West Virginia, Pensilvania y Kentucky) para salarios devengados por viajeros diarios.
