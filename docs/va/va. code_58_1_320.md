# Va. Code Ann. § 58.1-320 — Rates of Tax on Individuals

- **Jurisdiction:** VA
- **Corpus:** Va. Code
- **Effective Year:** 2024
- **Superseded Year:** Current / In Force
- **Source:** [https://law.lis.virginia.gov/vacode/title58.1/chapter3/section58.1-320/](https://law.lis.virginia.gov/vacode/title58.1/chapter3/section58.1-320/)
- **Hierarchy:** `Va. Code > Title 58.1 > Chapter 3 > Article 2 > § 58.1-320`
- **Cross References:** `Va. Code Ann. § 58.1-302`, `Va. Code Ann. § 58.1-322.03`

## Operative Statutory Language (English)

Imposes Virginia individual income tax at graduated rates: 2.0% on the first $3,000; 3.0% on $3,001 to $5,000; 5.0% on $5,001 to $17,000; and 5.75% on taxable income exceeding $17,000.

## Texto Estatutario Oficial (Español)

Impone el impuesto sobre la renta individual de Virginia con tasas graduadas: 2.0% sobre los primeros $3,000; 3.0% de $3,001 a $5,000; 5.0% de $5,001 a $17,000; y 5.75% sobre el exceso de $17,000.
