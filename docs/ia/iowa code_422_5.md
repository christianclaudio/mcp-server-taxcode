# Iowa Code § 422.5 — Tax Imposed - Rates

- **Jurisdiction:** IA
- **Corpus:** Iowa Code
- **Effective Year:** 2024
- **Superseded Year:** Current / In Force
- **Source:** [https://www.legis.iowa.gov/law/statutory](https://www.legis.iowa.gov/law/statutory)
- **Hierarchy:** `Iowa Code > Title X > Subtitle 2 > Chapter 422 > Subchapter II > § 422.5`
- **Cross References:** 

## Operative Statutory Language (English)

Imposes personal income tax transitioning to a flat 3.80% rate under SF 2442 in Iowa.

## Texto Estatutario Oficial (Español)

Impone impuesto sobre la renta personal en transición hacia una tasa fija uniforme del 3.80% bajo SF 2442 en Iowa.
