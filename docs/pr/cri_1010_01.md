# PR CRI Sec. 1010.01 — Definiciones generales / General Definitions

- **Jurisdiction:** PR
- **Corpus:** CRI
- **Effective Year:** 2011
- **Superseded Year:** Current / In Force
- **Source:** [https://hacienda.pr.gov/publicaciones/codigo-de-rentas-internas-de-puerto-rico-de-2011](https://hacienda.pr.gov/publicaciones/codigo-de-rentas-internas-de-puerto-rico-de-2011)
- **Hierarchy:** `Ley 1-2011 > Subtítulo A > Capítulo 1 > Sección 1010.01`
- **Cross References:** `PR CRI Sec. 1031.01`, `PR CRI Sec. 1062.01`

## Operative Statutory Language (English)

Defines fundamental statutory terms under the PR Internal Revenue Code (Ley 1-2011), including resident individual (domiciled in PR or present for entire tax year), foreign corporation, taxable year, and person.

## Texto Estatutario Oficial (Español)

Define términos fundamentales bajo el Código de Rentas Internas de Puerto Rico (Ley 1-2011), incluyendo individuo residente (domiciliado en PR o presente durante el año contributivo), corporación foránea y año contributivo.
