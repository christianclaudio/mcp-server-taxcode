# PR CRI Sec. 1010.01 — Definiciones generales / General Definitions

- **Jurisdiction:** PR
- **Corpus:** CRI
- **Effective Year:** 2011
- **Superseded Year:** Current / In Force
- **Source:** [https://hacienda.pr.gov/sites/default/files/codigo_de_rentas_internas_2011_segun_enmendado_28.08.2026.pdf](https://hacienda.pr.gov/sites/default/files/codigo_de_rentas_internas_2011_segun_enmendado_28.08.2026.pdf)
- **Hierarchy:** `Ley 1-2011 > Subtítulo A > Capítulo 1 > Sección 1010.01`
- **Cross References:** `PR CRI Sec. 1031.01`, `PR CRI Sec. 1062.01`

## Operative Statutory Language (English)

Defines fundamental statutory terms under the PR Internal Revenue Code (Ley 1-2011), including resident individual (domiciled in Puerto Rico; presumed resident if present in Puerto Rico 183 days during the calendar year), foreign corporation, taxable year, and person.

## Texto Estatutario Oficial (Español)

Define términos fundamentales bajo el Código de Rentas Internas de Puerto Rico (Ley 1-2011), incluyendo individuo residente (domiciliado en Puerto Rico; se presume residente si estuvo presente en Puerto Rico 183 días durante el año natural), corporación extranjera y año contributivo.
