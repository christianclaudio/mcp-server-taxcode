# Md. Code Ann., Tax-Gen. § 10-106 — County and Local Piggyback Income Tax

- **Jurisdiction:** MD
- **Corpus:** Md. Code
- **Effective Year:** 2024
- **Superseded Year:** Current / In Force
- **Source:** [https://mgaleg.maryland.gov/mgawebsite/Laws/StatuteText?article=gtg&section=10-106](https://mgaleg.maryland.gov/mgawebsite/Laws/StatuteText?article=gtg&section=10-106)
- **Hierarchy:** `Md. Code > Tax-General > Title 10 > Subtitle 1 > § 10-106`
- **Cross References:** `Md. Code Ann., Tax-Gen. § 10-105`

## Operative Statutory Language (English)

Mandates that each Maryland county and Baltimore City levy a local piggyback income tax rate between 2.25% and 3.20%, collected by the Comptroller on the state tax return.

## Texto Estatutario Oficial (Español)

Requiere que cada condado de Maryland y la ciudad de Baltimore cobren un impuesto local sobre la renta ('piggyback') de entre 2.25% y 3.20%, recaudado en la planilla estatal.
