# Md. Code Ann., Tax-Gen. § 10-105 — Individual State Income Tax Rates

- **Jurisdiction:** MD
- **Corpus:** Md. Code
- **Effective Year:** 2024
- **Superseded Year:** Current / In Force
- **Source:** [https://mgaleg.maryland.gov/mgawebsite/Laws/StatuteText?article=gtg&section=10-105](https://mgaleg.maryland.gov/mgawebsite/Laws/StatuteText?article=gtg&section=10-105)
- **Hierarchy:** `Md. Code > Tax-General > Title 10 > Subtitle 1 > § 10-105`
- **Cross References:** `Md. Code Ann., Tax-Gen. § 10-101`, `Md. Code Ann., Tax-Gen. § 10-106`

## Operative Statutory Language (English)

Imposes graduated Maryland state income tax rates from 2.0% up to 5.75% for taxable income exceeding $250,000 for single filers or $300,000 for married couples filing jointly.

## Texto Estatutario Oficial (Español)

Impone tasas impositivas estatales graduadas desde 2.0% hasta 5.75% sobre el ingreso gravable que exceda de $250,000 (solteros) o $300,000 (casados rindiendo conjuntamente).
