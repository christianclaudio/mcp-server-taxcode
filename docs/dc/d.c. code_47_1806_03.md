# D.C. Code § 47-1806.03 — Tax on Residents - Rates

- **Jurisdiction:** DC
- **Corpus:** D.C. Code
- **Effective Year:** 2024
- **Superseded Year:** Current / In Force

## Operative Statutory Language (English)

Imposes graduated personal income tax rates from 4.0% to top rate 10.75% for taxable income exceeding $1,000,000 in the District of Columbia.

## Texto Estatutario Oficial (Español)

Impone tasas de impuesto sobre ingresos personales graduadas desde 4.0% hasta tasa máxima de 10.75% sobre ingresos superiores a $1,000,000 en el Distrito de Columbia.
