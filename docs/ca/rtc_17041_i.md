## Unofficial Reference Summary (English)

California generally computes the effective tax rate using total taxable income as if resident, then applies the California taxable-income ratio. The California column combines resident-period worldwide income with nonresident-period California-source income. Applying brackets only to state-source income can understate tax.

## Resumen de referencia no oficial (Español)

California generalmente calcula la tasa efectiva usando el ingreso tributable total como si hubiera residencia y después aplica la proporción estatal. La columna de California combina ingreso mundial del período residente con fuente estatal del no residente. Aplicar tablas solo al ingreso estatal puede subestimar el impuesto.
