# Idaho Code § 63-3024 — Individuals' Tax and Tax on Estates and Trusts

- **Jurisdiction:** ID
- **Corpus:** Idaho Code
- **Effective Year:** 2024
- **Superseded Year:** Current / In Force
- **Source:** [https://legislature.idaho.gov/statutesrules/idstat/title63/t63ch30/sect63-3024/](https://legislature.idaho.gov/statutesrules/idstat/title63/t63ch30/sect63-3024/)
- **Hierarchy:** `Idaho Code > Title 63 > Chapter 30 > § 63-3024`

## Operative Statutory Language (English)

Imposes a flat individual income tax rate of 5.695% on taxable income under HB 521 in Idaho.

## Texto Estatutario Oficial (Español)

Impone una tasa impositiva individual fija del 5.695% sobre el ingreso gravable de individuos bajo HB 521 en Idaho.
